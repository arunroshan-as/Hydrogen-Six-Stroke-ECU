# 07 — Roadmap

| Phase | Goal | Output |
|---|---|---|
| 0 (current) | Concept + simulation | This repository |
| 1 | Publish model inputs and reproducible sweep scripts | Open model files, data tables |
| 2 | Multi-cylinder phasing and firing-order study | Phasing report |
| 3 | Software-in-the-loop ECU logic on a PC | Tested C/C++ ports of schedule and state machine |
| 4 | Target bring-up on S32G-VNP-RDB2 | Boot, timers, CAN/Ethernet, angle-based scheduler |
| 5 | Hardware-in-the-loop with engine model | HIL test report |
| 6 | Single-cylinder bench trial of the six-stroke cycle | Measured data to validate or revise the efficiency claim |
| 7 | Safety and regulatory review | Hazard analysis, ISO 26262 planning |

Contributions at phases 1–3 are especially welcome.
